# 苏华食养状态观察卡

用户上传本人照片并主动选择近期生活状态，系统通过服务端调用小吉图片接口生成视觉卡，再给出仅基于用户自述信息的日常食养建议和联系信息。支持的自述方向包括排便不规律、自觉气色偏黄/暗、肠道舒适、紧张压力和持续低落等。

照片只用于视觉生成，报告只来自用户自述；严禁通过脸部或照片诊断便秘、焦虑症、抑郁症、肠道疾病或作其他健康推断。生活建议不能替代专业医疗建议。用户自述持续低落时必须提示寻求合格专业人员帮助；出现自伤风险时必须提示立即联系当地急救/危机干预资源及可信赖的人。

## 本地运行

1. 复制 `.env.example` 为 `.env`，填写服务端 `XIAOJI_API_KEY`。
2. 安装依赖：`npm install`
3. 启动前后端：`npm run dev`
4. 打开 `http://localhost:5173`

前端只调用同源 `POST /api/analyze`。API Key 仅由 Express 服务端读取，不会进入浏览器构建产物。

## 验证

- 单元与接口测试：`npm test`
- 生产构建：`npm run build`
- 生产服务：先构建，再设置 `NODE_ENV=production` 并运行 `npm start`

部署前仍需补充真实运营主体、联系方式、正式隐私政策链接及服务商数据处理条款。详见 `docs/privacy-and-compliance.md` 和 `docs/qa-checklist.md`。
