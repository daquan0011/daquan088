# 苏华食养状态观察卡 QA 验收清单

## 0. 验收前提

- [ ] 记录待验收的 commit、环境、浏览器、设备和上游接口版本。
- [ ] 明确区分基线已实现功能与本次候选版本；`main@f10a402` 仅有初始化页面和 `GET /api/health`，不能按完整产品验收为通过。
- [ ] 测试账号、图片和网络日志不包含真实用户敏感信息。
- [ ] 上线环境已补隐私政策、真实运营主体和实际联系方式；仓库当前未提供真实联系方式，不接受虚构占位内容。

## 1. 桌面与移动布局

- [ ] 在主流桌面浏览器验证常见宽度，内容无重叠、截断、横向滚动或不可见 CTA。
- [ ] 在 iOS Safari 和 Android Chrome 验证窄屏、横竖屏和软键盘场景。
- [ ] 上传区、预览、同意项、错误信息、生成结果和操作按钮在 320 px 宽度仍可用。
- [ ] 生成中、长错误文案和长关键词不会引发布局跳动或遮挡。

## 2. 上传与预览

- [ ] 可通过文件选择器选择一张本人照片，选择后显示本地预览。
- [ ] 支持 `png`、`jpg/jpeg`、`webp`、`gif`，服务端按文件内容校验，不只信任扩展名或 MIME 声明。
- [ ] 每种支持格式均完成真实上传和生成测试；GIF 明确按单图输入处理，不承诺保留动画。
- [ ] 拒绝不支持格式、伪造扩展名、空文件、损坏文件和多文件提交，并显示可理解原因。
- [ ] 接受恰好 10 MB 的合法文件，拒绝超过 10 MB 的文件；客户端与服务端结论一致。
- [ ] 重新选择会替换旧文件并撤销旧对象 URL；“清除照片”会清空文件引用和前端预览。
- [ ] 刷新、后退再前进或关闭重开后不会意外恢复照片。
- [ ] EXIF 方向显示正确；若实现元数据清理，验证服务端转发文件不含非必要 EXIF。

## 3. 隐私同意

- [ ] 同意框默认未勾选，未同意时“生成观察卡”不可用且没有照片网络请求。
- [ ] 同意文案紧邻操作，说明敏感照片、处理目的、服务端转发、服务商和保存说明，并可进入完整隐私政策。
- [ ] 更换照片后需要确认本次发送，同意记录包含政策版本、时间和请求 ID，不含照片。
- [ ] 清空前端预览的文案不声称已删除上游数据。
- [ ] 页面准确表述“上游文档声称原图处理后 10 分钟删除”，不包装成项目独立保证。
- [ ] 页面说明生成图可能由服务商托管，并与实际配置、期限和删除流程一致。

## 4. 生成接口与数据流

- [ ] 浏览器只调用同源站内接口，不直接访问上游 `/v1/images/edits`。
- [ ] 服务端向配置的 Base URL `/v1` 发起 `POST /images/edits`，请求为 `multipart/form-data`。
- [ ] 上游 multipart 只包含必要字段：`image`、`model`、`prompt`、`size`。
- [ ] `model` 和 `size` 由服务端白名单控制，不能被客户端注入任意值。
- [ ] `prompt` 仅使用用户主动选择的信息，不包含从照片得出的医学、健康或面相结论。
- [ ] 支持排便不规律、自觉气色偏黄/暗、肠道舒适、紧张压力、持续低落等用户自述方向；报告字段均可追溯至自述，不由照片识别、补全或验证。
- [ ] 分别以相同自述搭配不同照片测试，生活建议和报告事实不因脸部、肤色或五官变化；不得从脸诊断便秘、焦虑症、抑郁症或肠道疾病。
- [ ] 服务端约 120 秒超时生效，超时后中止上游请求并释放图片内存。
- [ ] 应用服务端原图不落盘、不进入数据库/对象存储/持久队列/备份；进程临时目录无残留。
- [ ] 请求日志、APM、错误监控和代理日志不包含图片、multipart 正文、完整 prompt、密钥或签名 URL。

## 5. API 失败与降级

- [ ] 400 输入错误能定位需修正项，且不清空用户已选状态。
- [ ] 413 明确提示 10 MB 上限；415 列出支持格式。
- [ ] 429 提示稍后重试，不进行无上限自动重试。
- [ ] 500/502 使用通用错误和请求 ID，不展示堆栈、内部地址或上游原始错误。
- [ ] 约 120 秒超时映射为 504 或等效稳定错误，页面明确显示超时并允许手动重试。
- [ ] 断网、DNS 失败、连接中断、上游畸形 JSON、缺少结果字段和图片 URL 失效均有可恢复状态。
- [ ] 失败时不生成模板图冒充成功，不重复扣费式提交，不无限轮询。
- [ ] 快速重复点击只产生一个有效生成请求；请求完成后状态可恢复。
- [ ] 真实请求在 20 秒内成功时，成功页不早于 20 秒展示；20 秒届满但请求未完成时仍显示生成中，不生成模板结果或假成功。
- [ ] 请求在 20 秒内失败时立即如实显示错误，不为凑足最低加载时长延迟错误；约 120 秒后按真实超时处理。

## 6. 下载与复制

- [ ] 成功结果可下载，文件可打开，扩展名和 Content-Type 与实际格式一致。
- [ ] 下载文件名稳定且不包含用户姓名、状态或其他敏感信息。
- [ ] 跨域图片下载不暴露 API Key、内部 URL或长期有效的签名参数。
- [ ] “复制关键词”成功后仅在 Clipboard API 确认成功时提示已复制。
- [ ] 剪贴板权限拒绝或 API 不可用时，关键词可聚焦并手动选择，且不误报成功。

## 7. 键盘与辅助功能

- [ ] 仅使用键盘可完成选图、状态选择、同意、生成、下载、复制、重新选择和清除。
- [ ] Tab 顺序符合视觉和操作顺序，焦点清晰可见，无键盘陷阱。
- [ ] 上传控件、复选框和按钮具有可访问名称；图标按钮有名称和提示。
- [ ] 禁用 CTA 向辅助技术表达禁用状态；生成中表达忙碌状态并防止重复操作。
- [ ] 校验错误与对应字段关联，失败后焦点移动到错误摘要或首个错误项。
- [ ] 生成结果图片有适当替代文本，状态变化通过可访问实时区域通知。
- [ ] 文本与控件对比度、触控目标尺寸和 200% 缩放满足可用性要求。

## 8. 内容安全与违禁词

- [ ] 页面、prompt、生成结果和错误文案均无医学诊断、治疗、处方、治愈或疗效保证。
- [ ] 无“面相”“看脸识病”及从脸色、五官、皮肤推断疾病、体质、气血、脏腑、营养、心理、性格或命运的内容。
- [ ] “自觉气色偏黄/暗”只作为用户自述显示，不出现“系统看出”“照片显示”等暗示图像判断的表述。
- [ ] 用户选择“持续低落”时明确提示寻求合格专业人员帮助，不输出抑郁症诊断或个体化治疗建议。
- [ ] 输入自伤、自杀或伤害自己的风险信息时立即出现固定安全提示，包含当地急救/危机干预资源、专业人员和可信赖的人；提示不等待图片生成且不宣称已完成风险分级。
- [ ] 不引导停药、停止就医或用观察卡替代专业意见。
- [ ] 关键词和下载文件名经过安全输出处理，不可注入 HTML、脚本、公式或路径字符。
- [ ] 对用户输入的提示词注入和越权字段进行测试，不能绕过服务端模板与白名单。
